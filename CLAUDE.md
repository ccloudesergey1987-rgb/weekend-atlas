# Weekend Atlas — правила проекта

## Что это
Интерактивный путеводитель «Барселона за 72 часа» бренда Weekend Atlas (короткие поездки по городам Европы на 2–4 дня). 
Это веб-приложение, которое работает и как обычный сайт в браузере, и как Telegram Mini App. 
Основная аудитория — в России, где Telegram ограничен, поэтому приложение обязано полностью работать без Telegram. 
Функции Telegram (тема, кнопка «Назад», CloudStorage) подключаются только если приложение открыто внутри Telegram.

## Владелец
Сергей, не программист, работает на Windows. Объясняй простым языком по-русски. 
Перед действиями вне папки проекта, удалением чего-либо, оплатами и работой с секретами — спрашивай.

## Стек
React + TypeScript + Vite, CSS Modules + CSS-переменные, React Router, Vitest (обязательно для расчётов бюджета). 
Telegram подключать через официальный скрипт telegram-web-app.js, вся работа с ним — только в src/telegram/telegram.ts. 
Новые библиотеки без реальной необходимости не добавлять.

## Экраны MVP
1. Главная. 
2. Маршрут: 3 дня, точки по порядку. 
3. Еда и места: фильтры по типу и цене. 
4. Калькулятор бюджета: диапазон мин–макс, без авиабилетов и жилья по умолчанию. 
5. Избранное: CloudStorage в Telegram, localStorage в браузере.

Не делать в MVP: встроенную карту, оплату, бэкенд, базу данных, авторизацию, выбор города, аналитику.

## Контент
- Все данные хранятся в JSON: src/data/<город>/ (city.json, route.json, places.json, budget.json), типы — в src/types/content.ts. Новый город — это новая папка без изменения компонентов.
- НИКОГДА не выдумывать рестораны, адреса, цены, часы работы и рейтинги. 
- У каждого факта и цены есть status ("verified" | "needs_check"), source и checkedAt. Непроверенное в интерфейсе помечается «Требует проверки».
- Карты — обычные ссылки Google Maps без API-ключей.
- Фото — только свои или с подходящей лицензией (например, Wikimedia Commons с указанием автора).

## Интерфейс
- Весь текст интерфейса только на русском, кроме названий бренда и мест.
- Премиальный редакционный стиль: крупные фото, много воздуха, чёткая типографика, удобно на телефоне (iPhone и Android).
- Без лишних экранов и декоративных элементов.

## Безопасность
Токены, ключи и пароли не хранить в коде и не отправлять в GitHub. 
Файл .env должен быть в .gitignore.

## Хостинг
Тестовая версия — GitHub Pages. 
Боевая — российский хостинг + собственный домен (выбор на этапе 4).
