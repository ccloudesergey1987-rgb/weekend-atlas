# Проверка перед запуском — 15 минут на телефоне

Сайт: https://ccloudesergey1987-rgb.github.io/weekend-atlas/

Отмечайте `[x]`. Если что-то не так — допишите в строке, что видите, и пришлите мне.

## 1. Telegram (5 минут)

Откройте путеводитель **как мини-приложение** — по ссылке на бота от BotFather (кнопка «Открыть» или меню бота).
Если бот ещё не настроен, отправьте ссылку на сайт себе в «Избранное» Telegram и откройте её там — проверятся пункты 1–2, а 3–5 останутся на потом.

- [ ] Открывается без белого экрана: сначала видно название «Барселона за 72 часа», через пару секунд — обложка.
- [ ] Цвета совпадают с темой Telegram: в тёмной теме Telegram путеводитель тоже тёмный.
- [ ] Перейдите в «Маршрут» → вверху Telegram появилась кнопка «Назад»; нажмите — вернулись на главную.
- [ ] Нажмите на любую внешнюю ссылку (например, «Открыть на карте») — открывается в браузере Telegram или в Google Maps, путеводитель не закрывается.
- [ ] Добавьте сердечком место в «Избранное», закройте мини-приложение и откройте на другом устройстве с тем же аккаунтом Telegram — место есть и там.

## 2. Главная и маршрут (4 минуты)

- [ ] На главной внизу: «Данные проверены: октябрь 2026», «Сообщить об ошибке», «Авторы фотографий».
- [ ] «Авторы фотографий» — список из 10 фото с авторами и лицензиями.
- [ ] Нажмите на подпись «Фото: …» на любом фото — открывается страница файла на Wikimedia Commons.
- [ ] «Маршрут» → переключите «День 1/2/3» — каждый день открывается сверху.
- [ ] У Барселонского собора нажмите «Подробнее» — видны часы, бронь, сайт и «Сообщить об ошибке».
- [ ] День 3, МНАК — видна подсказка про понедельник и CaixaForum с фото.
- [ ] Строка «≈ 20 мин пешком» между точками: нажмите — появляется «Оценка редакции».

## 3. Еда и места (3 минуты)

- [ ] В маршруте у обеда нажмите «Где поесть рядом» — открылся список, отфильтрованный по району.
- [ ] Включите фильтры «Рынки» и «€€€» — видно «Ничего не найдено» и кнопка «Сбросить фильтры».
- [ ] У любого заведения есть «Закрыто: …», «Рекомендуют: …», средний чек со значком ≈.
- [ ] Страница не сдвигается вбок, когда проводите пальцем по экрану.

## 4. Бюджет (3 минуты)

- [ ] По умолчанию (2 человека, «Средне», все места, T-casual, Аэробус туда-обратно) итог — **713–973 €**.
- [ ] Поставьте 5 человек и «Такси» — появляется «понадобится 2 машины».
- [ ] Выберите «Hola Barcelona» и «Метро L9» — сообщение, что поездки в аэропорт уже входят в проездной.
- [ ] Впишите в «Прочие расходы» `-5` — красное пояснение, сумма не учтена.
- [ ] Закройте и откройте приложение — выбор сохранился. «Сбросить» возвращает значения по умолчанию.

## Перед каждым обновлением гида

Что перепроверять и как часто. Команды выполняются в папке проекта.

| Что | Как | Когда |
|---|---|---|
| Все ссылки | `npm run check-links` — исправить всё из «Переадресация» и «Ошибка HTTP» | перед каждым обновлением и раз в месяц |
| Тесты и сборка | `npm test`, затем `npm run build` | перед каждым обновлением |
| Цены билетов (8 мест) | официальные сайты; у Ла Педреры и Каса Батльо цена «плавает» по дням | раз в 3 месяца и в январе (новые цены года) |
| Транспорт: T-casual, Hola, Аэробус, метро | tmb.cat, holabarcelona.com, aerobusbarcelona.es | в январе (тарифы меняются с 15 января) и раз в полгода |
| Такси | taxi.amb.cat — тариф и надбавка за аэропорт | в январе |
| Часы достопримечательностей | официальные сайты; сезонные переходы — март, май, октябрь, ноябрь | раз в 3 месяца и в месяцы смены сезона |
| Заведения | Google Maps: не закрыто ли, свежие отзывы, цена на человека, часы | раз в 2–3 месяца |
| Выходные дни | после проверки часов — `npm test` (тест «день недели × приём пищи» скажет, если в каком-то районе не осталось открытого места) | вместе с проверкой часов |
| Фото | при замене фото — `npm run photos`; лицензия только Public domain, CC0, CC BY, CC BY-SA | при замене |
| Дата проверки | `src/config/site.ts` → `DATA_CHECKED_LABEL` | после полной проверки данных |
| Чек-лист данных | `npm run checklist` → docs/data-checklist.md, «требует проверки» должно быть 0 | после любых правок данных |
